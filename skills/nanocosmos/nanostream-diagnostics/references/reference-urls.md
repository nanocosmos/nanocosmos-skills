## Severity Classification

| Severity | Definition |
|---|---|
| CRITICAL | Multiple streams down, platform outage, data loss |
| HIGH | Single production stream down, major feature broken |
| MEDIUM | Quality issues, non-critical features broken, API errors |
| LOW | Questions, minor issues, feature requests |
