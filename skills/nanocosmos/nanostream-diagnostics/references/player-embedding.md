## Web Page Integration / Player Embedding

### When to Use
A customer wants to add the nanoStream player to their own website or asks for a stream URL to use in their own player.

### Important Guidance
- **Do NOT provide raw stream URLs** for use in a custom player
- The H5Live Player (nanoPlayer) is JavaScript-based and works on all browsers (mobile and desktop)
- Customers should use the **embed code from the Dashboard** or the **HTML iframe snippet**

### Steps
1. Log in to the nanoStream Dashboard
2. Navigate to the stream
3. Copy the embed code or iframe snippet provided
4. Paste directly into the web page HTML

### Why Use the Embed Code
- Pre-configured with correct stream settings
- Includes all necessary JavaScript and styling
- Works across all browsers and devices
- Handles ABR switching automatically
- No need to construct stream URLs manually

### Customer Response Guidance
- Steer customers away from raw URLs and toward the Dashboard embed code
- For advanced integration, point to H5Live Player documentation

### Contact nanocosmos support when
- Customer has a specific integration requirement that the standard embed code cannot support
